# Employee System 👩‍💻

A Java project I made to practice **OOP Inheritance & Polymorphism**.  

The project has:  
- `Employee` (base class)  
- `Manager`, `Developer`, `Intern` (inherit from Employee)  
- `Payroll` to handle and print salaries  

This is just a training project for learning OOP.
